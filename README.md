# Arduino Bacteria Lab — Final Arduino Uno Collection

Проект искусственной жизни для **Arduino Uno** и  
**Seeed Studio 2.8" TFT Touch Shield v2.0**.

В этом репозитории сохранена полная история развития рабочей модели:
от первых бактерий с хемотаксисом до видов, родословных, атак, объектов остаточной биомассы,
колониального поведения, накопления повреждений и перемещающихся пищевых зон.

![Демонстрация](media/bacteria_lab_v0_2_demo.gif)

## Финальная версия для Arduino Uno

Основной скетч:

```text
versions/BacteriaLab_v2_7_Dynamic_Food_Zones_FINAL/
BacteriaLab_v2_7_Dynamic_Food_Zones_FINAL.ino
```

Это финальная экспериментальная версия ветки с родственным отбором.

Отдельный сценарий «все против всех» сохранён здесь:

```text
experiments/BacteriaLab_v2_4_Free_For_All/
BacteriaLab_v2_4_Free_For_All.ino
```

## Что умеет финальная версия

- движение и упрощённый хемотаксис;
- энергия, размножение и смерть;
- наследуемые параметры с мутациями;
- четыре вида бактерий;
- уникальный ID, родитель, поколение и потомки;
- выбор бактерии касанием;
- две страницы индивидуальных параметров;
- краткая статистика `A / B / D / F`;
- атаки при голоде;
- распознавание близких родственников;
- оранжевые остаточная биомасса, остающиеся до утилизации;
- наведение на обычную пищу и остаточная биомасса;
- задержка между размножениями;
- простое колониальное поведение;
- накопление повреждений и энергетический ремонт;
- перемещающиеся богатые пищевые зоны.

## Важное уточнение о генетике

В проекте используются **наследуемые генетические параметры**, мутации
и естественный отбор. Это не классический генетический алгоритм с
общей функцией fitness, централизованным выбором лучших и crossover.

Наследуемые параметры включают:

- `Speed`;
- `Sensor`;
- `Turn`;
- `Curiosity`;
- `Persistence`;
- `Repair`;
- `Species`.

## Виды и цвета

| Цвет | Вид | Основная стратегия |
|---|---|---|
| Зелёный | Explorer | дальний поиск и исследование |
| Синий | Sprinter | высокая скорость |
| Фиолетовый | Survivor | выживание и ремонт |
| Красный | Breeder | более раннее размножение |
| Жёлтый круг | Обычная пища | восстанавливает энергию |
| Оранжевый квадрат | Остаточная биомасса | остаётся до утилизации |

## Главная статистика

```text
A:4 B:8 D:4 F:3
```

| Обозначение | Значение |
|---|---|
| `A` | живые бактерии |
| `B` | всего родилось |
| `D` | всего погибло |
| `F` | активные источники обычной пищи |

## SELECT — параметры бактерии

Первая страница:

- `BACTERIA #` — уникальный ID;
- `Energy` — запас энергии;
- `Age` — возраст;
- `Type` — вид;
- `Parent` — ID родителя;
- `Gen` — поколение;
- `Child` — число непосредственных потомков;
- `Speed`, `Sensor`, `Turn`.

Вторая страница:

- `Curiosity`;
- `Persistence`;
- `Damage`;
- `Repair`;
- `Kills`;
- `Cool` — задержка до следующего размножения;
- краткие значения скорости, сенсора и поворота.

Нажатие `SELECT` переключает страницы. `START` возвращает в симуляцию.

## Оборудование

- Arduino Uno;
- Seeed Studio 2.8" TFT Touch Shield v2.0;
- USB-кабель.

## Библиотека

Установите:

```text
TFT_Touch_Shield_v2.0
```

Не устанавливайте одновременно отдельную `Touch_Screen_Driver`, поскольку
дублирующиеся файлы `SeeedTouchScreen.cpp` и `SeeedTouchScreen.h` могут
вызвать ошибку `multiple definition`.

## Как открыть скетч

1. Откройте нужную папку версии.
2. Запустите `.ino` с тем же именем, что и папка.
3. Выберите `Инструменты → Плата → Arduino Uno`.
4. Выберите COM-порт.
5. Нажмите `Проверить`, затем `Загрузить`.

## Наблюдения экспериментов

В малой популяции Arduino Uno результат сильно зависит от стартовых
расстояний, тесноты, случайных событий и первых успешных размножений.
В проведённых опытах синие Sprinter часто доминировали как при
родственном отборе, так и в режиме «все против всех». Это наблюдение
не следует считать универсальным биологическим выводом: модель мала,
а стоимость высокой скорости ещё требует отдельной калибровки.

## Ограничения

- максимум живых бактерий в финальном скетче: `16`;
- максимум одновременно хранимых объектов остаточной биомассы: `8`;
- Arduino Uno имеет 2 КБ SRAM и ограниченную производительность;
- модель упрощённая и не является точной биологической симуляцией;
- крупные дальнейшие эксперименты логичнее переносить на ESP32.
