# Arduino Bacteria Lab

Модель искусственной жизни для **Arduino Uno** и  
**Seeed Studio 2.8" TFT Touch Shield v2.0**.

Бактерии ищут пищу с помощью упрощённого хемотаксиса, расходуют энергию,
размножаются, наследуют гены с мутациями, стареют и умирают. У каждой
бактерии есть короткая память запаха и собственная родословная.

![Демонстрация](media/bacteria_lab_v0_2_demo.gif)

## Текущая версия

Релиз репозитория: **v0.3.0 — Lineage and generations**

Основной скетч:

```text
BacteriaLab_v1_7_Lineage_Stats/BacteriaLab_v1_7_Lineage_Stats.ino
```

## Возможности

- движение бактерий;
- упрощённый хемотаксис;
- четыре источника пищи;
- энергия, размножение и смерть;
- наследование генов и мутации;
- короткая память запаха;
- возраст и старение;
- погибшая бактерия превращается в пищу;
- статистика популяции;
- сенсорные кнопки `START`, `PAUSE`, `SELECT`, `STOP`;
- выбор отдельной бактерии касанием;
- просмотр её энергии и генов;
- уникальный ID бактерии;
- ID родителя;
- номер поколения;
- число потомков;
- статистика родословных и поколений.

## Оборудование

- Arduino Uno;
- Seeed Studio 2.8" TFT Touch Shield v2.0;
- USB-кабель.

## Библиотеки

Нужно установить:

- `TFT_Touch_Shield_v2.0`.

В состав этой библиотеки входит `SeeedTouchScreen.h`.

Следующие библиотеки уже входят в Arduino IDE и отдельно не устанавливаются:

- `SPI`;
- `stdint`;
- `math`.

**Не устанавливайте одновременно отдельную библиотеку
`Touch_Screen_Driver`.** Она содержит дублирующиеся файлы
`SeeedTouchScreen.cpp` и `SeeedTouchScreen.h` и вызывает ошибку
`multiple definition`.

## Запуск

1. Установите TFT Shield на Arduino Uno.
2. Откройте файл:

```text
BacteriaLab_v1_7_Lineage_Stats/BacteriaLab_v1_7_Lineage_Stats.ino
```

3. В Arduino IDE выберите:

```text
Инструменты → Плата → Arduino Uno
```

4. Выберите порт Arduino.
5. Нажмите **Загрузить**.

## Управление

| Кнопка | Действие |
|---|---|
| `START` | Продолжить после паузы; после `STOP` начать новый эксперимент |
| `PAUSE` | Заморозить симуляцию |
| `SELECT` | Остановить симуляцию и перейти к выбору бактерии |
| `STOP` | Остановить эксперимент и очистить игровое поле |

После нажатия `SELECT` коснитесь бактерии. Для возврата к симуляции
нажмите `START`.

## Цвета объектов

| Цвет | Значение |
|---|---|
| Синий | Бактерия со скоростью `1` |
| Зелёный | Бактерия со скоростью `2` |
| Фиолетовый | Бактерия со скоростью `3` |
| Жёлтый круг | Источник пищи |
| Чёрный | Фон и очистка старых позиций |

Быстрые бактерии двигаются быстрее, но расходуют больше энергии.

## Цвета интерфейса

| Цвет | Значение |
|---|---|
| Зелёный | `START`, энергия выбранной бактерии |
| Жёлтый | `PAUSE`, подсказка возврата |
| Голубой | `SELECT`, возраст и строка средних генов |
| Красный | `STOP`, ошибки выбора и сообщение остановки |
| Белый | Основная статистика и параметры бактерии |

## Первая строка статистики

```text
A:4 B:8 D:4 F:3
```

| Показание | Значение |
|---|---|
| `A` — Alive | Число живых бактерий |
| `B` — Born | Сколько бактерий родилось с начала эксперимента |
| `D` — Dead | Сколько бактерий погибло |
| `F` — Food | Сколько источников пищи существует сейчас |

## Вторая строка статистики

Вторая строка автоматически переключается каждые три секунды.

### Средние параметры живой популяции

```text
Age:620 Sp:2 Se:13 Tu:34
```

| Показание | Значение |
|---|---|
| `Age` | Средний возраст живых бактерий |
| `Sp` | Средний ген скорости |
| `Se` | Средняя дальность сенсора |
| `Tu` | Средний ген силы поворота |

### Родословная живой популяции

```text
Gen:4 Old:17 Ch:3
```

| Показание | Значение |
|---|---|
| `Gen` | Максимальный номер поколения среди живых бактерий |
| `Old` | ID самой старой живой бактерии |
| `Ch` | Максимальное число потомков у одной живой бактерии |

## Экран выбранной бактерии

После `SELECT` отображаются:

| Показание | Значение |
|---|---|
| `BACTERIA #` | Уникальный ID бактерии |
| `Energy` | Текущий запас энергии |
| `Age` | Возраст в тактах симуляции |
| `Parent` | ID родителя; `0` означает основателя |
| `Gen` | Номер поколения |
| `Child` | Число непосредственных потомков |
| `Speed` | Ген скорости |
| `Sensor` | Дальность химического сенсора |
| `Turn` | Сила поворота к более сильному запаху |
| `Cur` | Вероятность исследовательского поворота |
| `Pers` | Настойчивость при ухудшении запаха |

## Ограничения

Это экспериментальная упрощённая модель искусственной жизни, а не
точная биологическая симуляция. Arduino Uno ограничивает объём памяти,
размер популяции и сложность химической среды.
